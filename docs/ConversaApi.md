## 🆓 APIs Gratuitas para Dados Desportivos

### ⚽ Futebol

**1. API-Football (api-sports.io)**
O plano gratuito dá acesso a todos os endpoints, sem cartão de crédito, e permanece gratuito para sempre. Inclui também acesso gratuito a outras APIs: basquetebol, baseball, fórmula 1, hóquei, MMA, NFL, rugby, voleibol, entre outros. O limite é de 100 requests/dia no free tier.

**2. TheSportsDB**
Oferece uma API JSON gratuita com uma grande variedade de desportos, desde as principais ligas (NFL, NBA) até ligas menos conhecidas. Inclui rosters de equipas, informações de jogadores, estatísticas de eventos e dados históricos.

**3. StatsBomb Open Data (GitHub)**
Dados gratuitos em formato JSON exportados diretamente da API StatsBomb. Inclui competições, jogos por época, eventos e lineups por jogo, e dados StatsBomb 360 para jogos selecionados. Ideal para análise de eventos detalhados (passes, ações individuais).

**4. OpenFootball / football.db**
Base de dados de futebol totalmente gratuita e open source, dedicada ao domínio público. Inclui calendários das principais ligas europeias para 2025/26 (Premier League, Bundesliga, Serie A, La Liga, Ligue 1, entre outras).

**5. Sportmonks (Free Plan)**
O plano gratuito é permanente, sem expiração nem taxas ocultas. Dá acesso a endpoints reais com dados estruturados para testar integrações — inclui a Danish Superliga e a Scottish Premiership.

---

### 🎾 Ténis / Multi-desporto

**6. API-Sports (Tennis)**
Cobre mais de 2.000 competições com mais de 15 anos de dados históricos, atualizações em tempo real a cada 15 segundos, e inclui odds pré-jogo e ao vivo em todos os planos.

**7. TheRundown API**
Plano gratuito com 20.000 data points/dia, sem cartão de crédito. Cobre odds, scores ao vivo e schedules para vários desportos incluindo ténis e futebol.

---

### 📊 Dados históricos sem limite (open data)

**8. football-data.co.uk** — Ficheiros CSV gratuitos com resultados históricos de dezenas de ligas europeias, muito usados em modelos preditivos. Sem API key, acesso direto por URL.

**9. FBref / WhoScored** (scraping)
O FBref é útil para dados agregados por semanas, épocas e carreiras. O WhoScored tem dados de eventos individuais (cada passe e ação durante um jogo).

---

### 💡 Recomendação para o teu caso

| Necessidade | Melhor opção gratuita |
|---|---|
| Futebol ao vivo + histórico | API-Football (api-sports.io) |
| Ténis ao vivo | API-Sports Tennis |
| Odds | TheRundown (20k/dia grátis) |
| Dados históricos detalhados | StatsBomb Open Data |
| Backup sem limites | football-data.co.uk (CSV) |
